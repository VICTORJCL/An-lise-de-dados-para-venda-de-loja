# Análise de Dados para Tomada de Decisão sobre Venda de Loja

## 📊 Descrição do Projeto

Este projeto visa auxiliar João na decisão de qual das suas quatro lojas deve ser vendida, baseando-se em uma análise de dados abrangente. Utilizamos dados fictícios importados de arquivos CSV contendo informações relevantes de cada loja.

## 📈 Análises Realizadas

A análise contempla os seguintes aspectos de cada loja:

- Faturamento total
- Média de avaliação dos clientes
- Vendas por categoria de produtos
- Produtos mais vendidos
- Produtos menos vendidos
- Frete médio

## 🔍 Metodologia

Os dados foram processados e visualizados através de tabelas e gráficos comparativos, permitindo uma decisão baseada em múltiplos critérios de desempenho.

## ⚙️ Requisitos para Execução

Para executar este projeto localmente, você precisará:

1. **Instalação de bibliotecas Python**:
   ```bash
   pip install pandas matplotlib numpy
   ```

2. **Ou simplesmente**:
   - Abrir o arquivo `.ipynb` no [Google Colab](https://colab.research.google.com/)

## 📁 Estrutura do Repositório

- `analise_lojas.ipynb`: Notebook principal com as análises e visualizações
- `dados/`: Diretório contendo os arquivos CSV de cada loja
- `README.md`: Este arquivo de documentação

## 🚀 Como Utilizar

1. Clone este repositório
2. Instale as dependências ou abra o notebook no Google Colab
3. Execute todas as células do notebook para visualizar as análises

## 📝 Resultados

Os resultados das análises são apresentados de forma visual no notebook, facilitando a comparação entre as lojas e auxiliando na tomada de decisão final.
