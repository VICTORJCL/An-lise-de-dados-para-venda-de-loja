# Análise de Dados para Escolha de Venda de uma das 4 Lojas

## Sobre o Projeto
Este projeto apresenta uma análise de dados que auxilia João na decisão de qual das suas quatro lojas deve ser vendida. Usando dados fictícios importados de arquivos CSV, analisamos o desempenho de cada estabelecimento.

## Indicadores Analisados
- Faturamento total por loja
- Média de avaliação dos clientes
- Vendas por categoria de produtos
- Produtos mais vendidos em cada loja
- Produtos menos vendidos em cada loja
- Frete médio por loja

Os resultados são apresentados através de tabelas e gráficos comparativos que facilitam a tomada de decisão baseada em dados.

## Como Executar o Projeto

### Pode abrir e visualizar já executado abrindo o arquivo no Github

###  Google Colab
A maneira mais simples de visualizar e executar este projeto é abrindo o arquivo notebook diretamente no Google Colab.

###  Execução Local
Para executar o notebook localmente, você precisa:
1. Clonar este repositório
2. Instalar as dependências necessárias:
```
pip install pandas matplotlib numpy
```
3. Executar o arquivo notebook `analise_lojas.ipynb`

## Estrutura de Arquivos
- `analise_lojas.ipynb` - Notebook contendo toda a análise de dados
- Pasta com arquivos CSV contendo os dados fictícios das lojas
